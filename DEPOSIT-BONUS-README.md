# New-user deposit promotion

The current policy is:

1. A new account does not receive a fixed bonus just for signing up.
2. When an investment deposit is approved, the account receives a 100%
   matching bonus for that deposit if it is deposit number one or two.
3. The third and later approved deposits receive no match.
4. The match is created as a processed ledger transaction only after admin
   approval. Repeating an approval cannot create a second match for the same
   deposit.
5. Withdrawals do not require a separate payment or a 30% deposit. Identity
   verification and normal admin review can still be required.

The bonus is reflected in the investment's current value and earnings, while
the original deposited principal remains recorded in `total`.
